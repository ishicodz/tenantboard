### What the tests prove

| Area | File | Key assertions |
|---|---|---|
| Tenant isolation | `tenancy.test.ts` | Non-members get 404; issues from tenant A cannot be read/edited/moved/commented/deleted through tenant B by id **or** key; cross-tenant project/status/assignee ids rejected; `tenantDb` returns null / 0 rows across tenants; spoofed `workspaceId` on create is overwritten |
| RBAC | `rbac.test.ts` | Viewer read-only; member can't manage projects/workflows/webhooks/audit; comment ownership; admins can't touch owners; last-owner protection; role changes audited |
| Issues & Kanban | `issues.test.ts` | Per-project keys (WEB-1, WEB-2); drag-and-drop ordering across/within columns; rank rebalancing after 60 midpoint inserts; `resolvedAt` lifecycle; enforced workflow transitions; status delete/reorder; comments + notifications; upload/download/delete attachments; plan file-size limit |
| Sprints & reports | `sprints-reports.test.ts` | One active sprint per project; completion moves open issues to next sprint; report generated by background job with correct totals/points; CSV export |
| Webhooks | `webhooks.test.ts` | Blocked on FREE; HMAC signature verified by a real HTTP receiver; event filtering; failed delivery recorded with status code; redelivery; inactive hooks skipped |
| Billing | `billing.test.ts` | FREE limits (projects, members) return 402 with details; signed Stripe webhooks: checkout links customer, price id → plan, idempotent on duplicate event id, payment failure notifies owners, cancellation downgrades and re-enforces limits; bad signatures rejected |
| Units | `unit.test.ts` | Tenant arg rewriting for every Prisma operation, permission matrix, fractional ranking, plan mapping, signature round-trip + replay window, CSV escaping |

### Manual / end-to-end checks (also run)

- Full Docker Compose stack (Postgres, Redis, API, worker, nginx web): migrations on boot, seed, login through nginx, SPA deep links, attachment upload into the volume.
- BullMQ worker on real Redis: sprint report generated asynchronously; webhook endpoint returning 503 was retried with backoff and succeeded on attempt 2.
- Headless Chrome: real pointer drag of a card between columns persisted after reload; no console errors on any page.
