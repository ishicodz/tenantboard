## Demo script (3:00)

Prep: `docker compose up -d && docker compose run --rm seed`. Open two browser profiles: Profile A logged in as the demo owner, Profile B as a Globex-only user (create one first via the register page). Rehearse it twice.

1. **0:00 Board.** Acme → Web App board. Drag a card from To Do to In Review, then reorder within a column. Refresh to show the order persisted.
2. **0:30 Issue drawer.** Open the card, change assignee and priority, add a comment, attach a file. Open the Activity tab: the field-level history is there.
3. **1:10 Workflow.** Settings → Workflows → tick "Enforce transitions", allow only To Do → In Progress. Back on the board, try dragging To Do → Done: the column greys out and the move is refused.
4. **1:40 Isolation.** In Profile B, paste Profile A's workspace URL: "Workspace not found". (Optional: show the passing tenancy tests in the terminal.)
5. **2:00 Sprint + report.** Backlog → Complete sprint → open Reports: the report was generated by the background worker. Download CSV.
6. **2:30 Billing + webhooks.** Globex (Free) → Projects → create a 3rd project → plan-limit error. Billing → upgrade (Stripe test checkout with 4242…, or the dev switch). Webhooks → add a https://webhook.site URL → Send test → delivery shows SUCCESS.

Backup plan if the live demo breaks: a screen recording of exactly this script, which is also the "working demo" deliverable.
